# Museum Catalog
![Museum Catalog](IMAGES/museum.png)

## Требования
- Visual Studio 2019/2022
- .NET Framework 4.8
- NuGet-пакеты подтягиваются автоматически при сборке:
  - System.Data.SQLite.Core
  - DocX

## Сборка
1. Откройте MuseumCatalog.csproj в Visual Studio
2. Восстановите NuGet-пакеты (ПКМ по Solution → Restore NuGet Packages)
3. Соберите проект (Ctrl+Shift+B)
4. Запустите

## Первый запуск
1. Вкладка «Настройки» → «Создать новую БД» → укажите путь (например, C:\Museum\museum.db)
2. Укажите путь к файлу шаблона (Шаблон.docx)
3. Введите название музея
4. Нажмите «Сохранить настройки»
5. Перезапустите программу

## Технологии
- C# / WinForms / .NET Framework 4.8
- SQLite (System.Data.SQLite.Core) — локальная БД, без драйверов
- DocX — генерация Word-документов по шаблону


# Возможности программы MuseumCatalog

## 📜 Что может программа

### Управление экспонатами
- Добавление новых экспонатов: легко добавляйте новые объекты в вашу музейную коллекцию.
- Редактирование существующих экспонатов: изменяйте информацию о названиях, описаниях и местах хранения.
- Удаление экспонатов: быстро удаляйте ненужные объекты из базы данных.

### Поиск экспонатов
- Фильтрация по различным параметрам: находите экспонаты по номеру, названию, дате или месту хранения.
- Быстрый поиск: программа позволяет быстро находить нужные экспонаты среди множества записей.

### Просмотр информации
- Полный список экспонатов: просматривайте все экспонаты в вашей коллекции.
- Детальная информация: получайте подробную информацию о каждом экспонате, включая описание и место хранения.

### Управление местами хранения
- Выбор места хранения: назначайте каждому экспонату место хранения из списка доступных мест.

### Работа с базой данных
- Автоматическое управление данными: вся информация о экспонатах хранится в базе данных и управляется автоматически.
- Безопасность данных: данные защищены от ошибок и несанкционированного доступа.
- Одновременная работа: несколько пользователей могут работать с базой данных одновременно, не мешая друг другу.

### Удобный интерфейс
- Простой и понятный дизайн: интерфейс интуитивно понятен и удобен в использовании.
- Легкость в навигации: все функции доступны через удобные меню и формы.

### Экспорт данных
- Сохранение в Word: возможность сохранять информацию из карточек экспонатов в документы Microsoft Word для дальнейшей печати и использования.

## Основные функции
- Добавление новых экспонатов и их описание
- Редактирование информации об уже существующих экспонатах
- Поиск и фильтрация экспонатов по различным критериям
- Выбор места хранения для каждого экспоната
- Просмотр списка всех экспонатов и их детальной информации

Программа создана для того, чтобы упростить управление музейной коллекцией и сделать работу с экспонатами быстрой и удобной, обеспечивая при этом возможность совместной работы и удобный экспорт данных.
