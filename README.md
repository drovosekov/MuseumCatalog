# Museum Catalog
![Museum Catalog](IMAGES/museum.png)

## Требования
- Visual Studio 2019/2022
- .NET Framework 4.8
- NuGet-пакеты подтягиваются автоматически при сборке:
  - System.Data.SQLite.Core
  - DocX

## Сборка
1. Откройте MuseumCatalog.csproj в Visual Studio
2. Восстановите NuGet-пакеты (ПКМ по Solution → Restore NuGet Packages)
3. Соберите проект (Ctrl+Shift+B)
4. Запустите

## Первый запуск
1. Вкладка «Настройки» → «Создать новую БД» → укажите путь (например, C:\Museum\museum.db)
2. Укажите путь к файлу шаблона (Шаблон.docx)
3. Введите название музея
4. Нажмите «Сохранить настройки»
5. Перезапустите программу

## Технологии
- C# / WinForms / .NET Framework 4.8
- SQLite (System.Data.SQLite.Core) — локальная БД, без драйверов
- DocX — генерация Word-документов по шаблону

## Функционал

* Управление фондами: добавление, редактирование и удаление карточек экспонатов (изменение названий, описаний, мест хранения).
* Поиск и фильтрация: оперативный поиск объектов по инвентарному номеру, названию, дате или локации.
* Просмотр сведений: вывод полного списка коллекции и отображение детальной информации о каждом предмете.
* Учет мест хранения: закрепление за каждым экспонатом определенной локации из справочника доступных мест.
* Многопользовательская БД: безопасное хранение данных, защита от ошибок ввода и обеспечение одновременной работы нескольких сотрудников.
* Эргономичный интерфейс: интуитивно понятная навигация, доступ к функциям через лаконичные меню и формы.
* Экспорт в Word: выгрузка карточек экспонатов в формат Microsoft Word для последующей печати.

## MuseumCatalog оптимизирует учет музейных коллекций, обеспечивает высокую скорость обработки данных, совместный доступ и удобный экспорт отчетности.
